# Engineering lessons retained by the baseline

1. A technical HTTP result and ordinary-browser user acceptance are separate
   evidence categories.
2. A URL that is not referenced by the delivered document cannot establish the
   state of the actual static asset; this candidate therefore does not claim a
   delivered browser application.
3. Source observation time and server receipt time are different facts; neither
   should silently replace the other.
4. Missing data is an observed absence, not automatic proof of a cause.
5. Location privacy needs fail-closed behavior and must not be preserved by
   publishing a realistic substitute point.
6. A scanner supports privacy review but cannot replace manual and adversarial
   review.
7. A clean Git root is necessary when old history may contain private evidence.
