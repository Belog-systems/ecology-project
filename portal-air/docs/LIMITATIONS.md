# Limitations

- This is not a production deployment package or a topology diagram.
- It contains no live data and does not demonstrate operational availability.
- It contains no source credentials, source addresses or provider registration.
- It does not ingest station packets, write a database, or control a device.
- It does not include a public HTTP application, browser UI, map, coordinates or
  location state.
- It does not integrate an external WEATHER source or provider.
- It does not prove backup/restore, rollback/recovery, TLS, DNS, infrastructure
  or public-browser acceptance.
- It does not make the project public or select a project license.

The test suite is deliberately local and synthetic. Production claims must rely
on separate current evidence, not this repository alone.
