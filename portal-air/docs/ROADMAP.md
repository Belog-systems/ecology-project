# Deferred roadmap

The frozen V1 baseline intentionally does not implement the following items:

- self-hosted deployment/distribution;
- map rendering and map-provider replacement;
- generic Module API;
- separately developed frontend/layout;
- device store-and-forward and idempotent replay;
- external WEATHER integration or providers;
- deployment/rollback automation; and
- production backup/restore acceptance.

Each item needs its own bounded design, privacy/security review, evidence and
acceptance. This list is intent, not an authorization or implementation claim.
