# Privacy and location

No coordinates are included in this baseline. The retained source reader has no
own-station or external-location marker and cannot reconstruct a protected
location state. It intentionally does not supply a substitute point.

Location handling is fail-closed by omission: this candidate has no location
mode, state file or projection. Future location work requires a distinct privacy
review covering authoritative state custody, projection precision, persistence,
regeneration authority, failure behavior and ordinary-browser verification.

Do not add real locations, raw observations, identifiers, profiles, screenshots,
or configuration from a live environment to issues, examples or tests.
