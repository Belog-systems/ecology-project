# Публикационная заметка

Этот каталог - предложенная человекоориентированная публичная редакция документации Portal Air.

Он не заменяет внутренние canonical coordination/evidence/checkpoint документы. Перед публикацией рекомендуется:

1. сравнить публичный `docs/07_STATUS.md` с текущим authoritative checkpoint;
2. прогнать secret/privacy scan именно конечного public tree;
3. не копировать в public tree внутренние backup/evidence/handoff файлы;
4. при изменении production состояния обновлять только фактические статусы, не переписывая историю доказательств.

Технические инциденты описаны на уровне инженерных уроков без публикации credentials, приватных путей, session values или attack-relevant деталей.
