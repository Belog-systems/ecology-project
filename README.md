# Ecology Project

Публичный репозиторий экологического направления Belog-systems. Он объединяет человекоориентированные материалы по действующим и будущим компонентам системы экологического мониторинга, не смешивая публичную документацию с внутренними operational/evidence/backup/handoff материалами.

## Portal Air

[Portal Air V1 frozen sanitized baseline](portal-air/README.md) — curated reference tree, not a production deployment package. It retains a sanitized PM-source reader and documentation of privacy, security, time and missing-data boundaries.

Scope, limitations and safe local checks: [portal-air/docs/INDEX.md](portal-air/docs/INDEX.md).

## Будущее устройство мониторинга

В рамках экологического направления планируется отдельный контур собственного устройства мониторинга: аппаратная сборка, перечень компонентов, настройка, испытания и собственная firmware. Публичные материалы по этому направлению будут добавляться по мере появления подтверждённых проектных решений и evidence.

Раздел: [air-device/README.md](air-device/README.md).

## Граница публичной публикации

Этот репозиторий предназначен только для материалов, прошедших public-review. Внутренние `coordination/`, `evidence/`, backup/DR-артефакты, handoff-файлы, credentials, sessions, private configuration и иные operator-specific материалы сюда не переносятся автоматически.

Публичная документация не заменяет internal canonical/evidence/checkpoint документы проекта.
